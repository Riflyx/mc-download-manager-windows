Chrome / Edge / Brave eklentisi

Düğmeye basınca klasör yolu panoya kopyalanır ve tarayıcı eklentiler sayfasıyla açılır. Orada: Geliştirici modu → “Paketlenmemiş öğe yükle” → adres çubuğuna Ctrl+V → Enter → Klasör Seç.
  1. Eklenti klasörünü açın:
  2. Tarayıcıda şu adrese gidin: chrome://extensions
    Edge: edge://extensions · Brave: brave://extensions
  3. Sağ üstten “Geliştirici modu”nu açın.
  4. “Paketlenmemiş öğe yükle” deyip 1. adımdaki klasörü seçin.
    Klasör seçme penceresinde bu yolu üstteki adres çubuğuna yapıştırıp Enter'a basın.
